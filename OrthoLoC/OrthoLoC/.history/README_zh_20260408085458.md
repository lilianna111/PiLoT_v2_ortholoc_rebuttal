🎯 我们提出了一种利用地理空间数据进行无人机相机定位与标定的新范式，具体依赖正射影像（DOP）和数字表面模型（DSM）。
这一方法尤其适用于城市环境中的无人机作业场景，因为传统定位方法往往会受到复杂环境结构的影响。借助地理数据，即使在困难条件下也能获得较准确的定位和标定结果。
同时，我们还提供了一个大规模无人机视觉定位基准数据集，覆盖多种环境下的图像与地理数据，可用于研究和评测新的定位算法。
</p>

<a name="About-the-Project"></a>

## :star2: 项目简介

OrthoLoC 是一个基于正射地理数据进行无人机相机定位与标定的框架。项目提供了一个大规模数据集，以及利用正射影像和数字表面模型对无人机影像进行匹配、定位和标定的算法实现。

<a name="Dataset-Features"></a>

## :mag: 数据集特点

- **📸 大规模数据集：** 共 **16,427** 张高分辨率无人机图像，并提供高精度相机参数（内参和外参），覆盖**多个**地理环境（欧洲与美国）。
- **🛫 多高度：** 图像采集高度差异较大（23m-154m），覆盖多种视角和范围。
- **🔄 多视角：** 无人机姿态变化丰富，倾角范围大（0°-86.8°），具有较强挑战性。
- **🌍 多样地理环境：** 包含**城市** 🏙️、**乡村** 🌾、**高速公路** 🚗 和 **郊区** 🏡 等场景，并与高分辨率地理数据进行了对齐。
- **📍 高精度真值：** 无人机图像与地理数据成对标注，可用于精确的定位和标定评估，减少检索歧义并提高准确性。
- **🌐 良好的地理对齐：** 正射地图（正射影像与高程图）与无人机数据对齐良好，可支持精确定位和标定。
- **🔬 面向真实应用：** 为解耦的无人机定位和标定评估提供基础，便于面向真实场景部署。

<a name="Getting-Started"></a>

## :toolbox: 快速开始

<a name="Prerequisites"></a>

### :bangbang: 环境要求

- Python 3.10

你可以使用 conda 或 venv 创建虚拟环境：

```bash
conda create -n ortholoc python=3.10 -y
conda activate ortholoc
```

或者：

```bash
python3 -m venv ortholoc
source ortholoc/bin/activate
```

<a name="Installation"></a>

### :gear: 安装

#### 通过 pip 安装

你可以直接通过 GitHub 用 pip 安装该包：

```bash
pip install git+https://github.com/deepscenario/OrthoLoC.git
```

如果要强制启用 GPU 支持，可执行：

```bash
pip install "git+https://github.com/deepscenario/OrthoLoC.git#egg=ortholoc[gpu]" --extra-index-url https://download.pytorch.org/whl/cu118
```

#### 通过 git clone 安装

克隆项目：

```bash
git clone https://github.com/deepscenario/OrthoLoC.git
```

安装库：

```bash
cd OrthoLoC
pip install -e .
```

如果要启用 GPU 支持：

```bash
cd OrthoLoC
pip install -e ".[gpu]" --extra-index-url https://download.pytorch.org/whl/cu118
```

<a name="Download-the-Dataset"></a>

### :inbox_tray: 下载数据集

数据集地址： [OrthoLoC Dataset](https://cvg.cit.tum.de/webshare/g/papers/Dhaouadi/OrthoLoC/)

#### 重要说明

- 你可以手动下载数据集，也可以让脚本自动下载。
- 在脚本中既可以直接使用 URL，也可以使用相对路径访问数据集。
    - 相对路径示例：`"demo/samples/highway_forest.npz"` 会自动下载  
      `https://cvg.cit.tum.de/webshare/g/papers/Dhaouadi/OrthoLoC/demo/samples/highway_forest.npz`
    - URL 示例：将  
      `"https://cvg.cit.tum.de/webshare/g/papers/Dhaouadi/OrthoLoC/full/test_inPlace/"`  
      作为数据集的 `dataset_dir` 时，会自动下载整个文件夹。
- 数据集默认会下载到系统缓存目录。例如在 Ubuntu 上通常是 `~/.cache/ortholoc/`。你可以通过设置环境变量 `ORTHOLOC_CACHE_DIR` 来指定其他缓存路径。
- 如果在脚本中不设置 `--dataset_dir`，则会自动按需下载到上述缓存目录。

#### 通过 Shell 脚本批量下载

可以使用仓库自带的 `download_dataset.sh` 并行下载完整数据集：

```bash
# 默认使用 4 个并行进程，下载到 ./OrthoLoC_dataset
./download_dataset.sh

# 自定义输出目录，并使用 8 个并行进程
./download_dataset.sh /path/to/save 8
```

该脚本会跳过已存在的文件，因此中断后可以安全续传。

#### 通过 Python 批量下载

```python
from ortholoc.dataset import OrthoLoC
dataset = OrthoLoC(predownload=True)  # 将所有样本预下载到缓存
```

```text
│   │   ├──  ...
│   ├── test_outPlace                      # 结构与 train 相同
│   │   ├──  ...
```

`demo` 文件夹中包含原始格式的数据，例如查询图像 `.jpg` 和地理数据 `.tif`，同时还提供了一个 `samples` 文件夹，内含少量数据集样本，便于快速测试和调试。`full` 文件夹包含完整数据集，划分为四部分：`train`、`val`、`test_inPlace`、`test_outPlace`。其中 `train` 和 `val` 用于训练和验证，`test_inPlace` 与 `test_outPlace` 用于测试。`test_inPlace` 中的样本与 `train/val` 来自相同地点，而 `test_outPlace` 中的样本来自不同地点。

文件命名遵循以下模式：`L{location_id}_{type_of_the_sample}{sample_index}.npz`，其中：

- **location_id**：地点编号，例如 `L01`、`L02`
- **type_of_the_sample**：样本类型，例如 `"R"` 表示同域，`"xDOP"` 表示 DOP 域偏移，`"xDSM"` 表示 DSM 域偏移，`"xDOPDSM"` 表示 DOP 与 DSM 同时域偏移

### 样本内容

<div align="center"> 
  <img src="ortholoc/assets/sample_viz.png" alt="Dataset Sample" />
</div>

每个 `.npz` 文件包含以下键：

`['sample_id', 'image_query', 'point_map', 'image_dop', 'dsm', 'scale', 'extrinsics', 'intrinsics', 'keypoints', 'vertices', 'faces']`

- **sample_id**：样本 ID，字符串
- **image_query**：查询图像，形状为 `(H, W, 3)` 的 numpy 数组
- **point_map**：点图，形状为 `(H, W, 3)` 的 numpy 数组
- **image_dop**：DOP 图像，形状为 `(H_geo, W_geo, 3)` 的 numpy 数组，其中 `H_geo = W_geo = 1024`
- **dsm**：DSM 图像，形状为 `(H_geo, W_geo, 3)` 的 numpy 数组，其中 `H_geo = W_geo = 1024`
- **scale**：DOP 和 DSM 中单个像素对应的米尺度
- **extrinsics**：查询图的外参（world to cam），形状为 `(3, 4)` 的 numpy 数组，由三维重建获得
- **intrinsics**：查询图内参，形状为 `(3, 3)` 的 numpy 数组
- **keypoints**：查询图三维关键点，形状为 `(N, 3)` 的 numpy 数组
- **vertices**：局部网格三维顶点，形状为 `(M, 3)` 的 numpy 数组
- **faces**：局部网格三角面，形状为 `(L, 3)` 的 numpy 数组

<a name="Usage"></a>

## :wrench: 用法

如果你希望将该数据集作为 PyTorch Dataset 使用，可以这样做：

```python
from ortholoc.dataset import OrthoLoC

dataset = OrthoLoC(
    dataset_dir=None,  # 数据集路径；若为空会自动下载
    sample_paths=None,  # 样本路径；若设置 dataset_dir 则不能同时设置，例如 ["demo/samples/highway_rural.npz", "demo/samples/urban_residential_xDOPDSM.npz"]
    set_name='all',  # 数据集划分名称，可选 all, train, val, test_inPlace, test_outPlace
    start=0.,  # 数据集起始比例
    end=1.,  # 数据集结束比例
    mode=0,  # 0 表示全部样本，1 表示同域样本，2 表示 DOP 域偏移样本，3 表示 DOP+DSM 域偏移样本
    new_size=None,  # 图像的新尺寸（训练时有用）
    limit_size=None,  # 限制样本数量（调试时有用）
    shuffle=True,  # 是否打乱
    scale_query_image=1.0,  # 查询图缩放比例，1.0 表示保持原始尺寸
    scale_dop_dsm=1.0,  # DOP 和 DSM 的缩放比例
    gt_matching_confidences_decay=1.0,  # GT 匹配置信度衰减，值越大表示对不唯一点更不自信，例如立面点
    covisibility_ratio=1.0,  # 共视区域比例，范围为 (0.0, 1.0]，值越大表示地理数据中更多区域对无人机可见
    return_tensor=False,  # 若为 True，迭代时返回 torch tensor 字典
    predownload=False,  # 若为 True，在构造数据集对象时下载；否则在迭代时按需下载
)
```

你也可以使用解包后的数据集版本，其中不同数据类型分别存放在独立文件夹中。这在使用 C++ 或其他不支持直接读取 `.npz` 的语言时比较方便。当然，在 C++ 中你也可以借助 [cnpy](https://github.com/rogersce/cnpy) 等库读取 `.npz` 文件。

你也可以通过直接指定文件路径来使用自己的图像和地理数据：

```bash
run-localization --image assets/demo/urban_residential.jpg --dop assets/demo/urban_residential_DOP.tif --dsm assets/demo/urban_residential_DSM.tif --intrinsics assets/demo/urban_residential_intrinsics.json --matcher Mast3R --device cuda --angles 0 --show
```

**重要说明：**

- 你可以添加 `--adhop` 启用 AdHoP refinement。
- 如果不提供内参，系统会自动估计内参，也就是执行标定。
- 请确保地理数据覆盖了查询图中的可见区域。该定位与标定框架要求查询图和地理数据之间具有足够重叠；如果地理数据中大量区域在查询图中不可见，可能会导致效果变差。
